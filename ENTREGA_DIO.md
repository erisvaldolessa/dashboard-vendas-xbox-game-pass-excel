# Entrega do projeto — DIO

## Nome sugerido do repositório

`dashboard-vendas-xbox-game-pass-excel`

## Descrição curta do repositório GitHub

Dashboard interativo de vendas e assinaturas Xbox Game Pass desenvolvido em Excel, com KPIs, gráficos, filtros, validação dos registros e documentação do desafio DIO.

## Texto para o formulário da DIO

Desenvolvi um dashboard de vendas e assinaturas do Xbox Game Pass utilizando Microsoft Excel e a base disponibilizada no desafio da DIO. O painel reúne indicadores de valor total, quantidade de assinaturas, valor médio, renovação automática, adicionais e descontos, além de gráficos para análise dos registros por mês de início, plano e periodicidade. Implementei filtros interativos, conferência dos cálculos e documentação com orientações para reprodução, metodologia e limitações dos dados. O projeto final foi publicado em repositório público no GitHub, contendo o arquivo Excel e imagens demonstrativas.

> Use a frase "foi publicado" **somente após** efetivamente publicar o repositório.

## Procedimento de publicação

1. Crie um novo repositório público em `https://github.com/new`.
2. Use o nome sugerido acima. Mantenha **Add README** desligado e não adicione `.gitignore` pelo GitHub (já está incluído no pacote).
3. **Extraia o ZIP.** Na pasta extraída, selecione os **oito arquivos**, incluindo as duas imagens.
4. No GitHub, utilize `Add file → Upload files` e arraste **os arquivos, não a pasta e não o ZIP**, para a raiz do repositório.
5. Confirme se `README.md`, o arquivo `.xlsx`, os três documentos `.md`, as duas imagens `.png` e `.gitignore` estão listados.
6. Clique em `Commit changes`.
7. Confira se **as duas imagens aparecem no README**. Os links Markdown utilizam os arquivos na raiz, evitando caminhos de subpastas.
8. No desafio da DIO, clique em **Entregar Projeto**, informe a URL real do repositório público e cole o texto acima.
